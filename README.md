# על הדרך — אפליקציית אנדרואיד

עטיפה של אפליקציית האנדרואיד לאפליקציית הריצה. המסכים נטענים מהאתר https://amitbusi10-pixel.github.io/run/, ולכן כל עדכון של האתר מגיע גם לאפליקציה בלי להתקין מחדש.

מה העטיפה מוסיפה על האתר:
- GPS שממשיך לעבוד כשהמסך כבוי או כשיוצאים מהאפליקציה (שירות רקע עם התראה קבועה).
- התראה במסך הנעילה עם הזמן והמרחק.
- שיתוף תמונה ושמירת קבצים, שלא עובדים בדפדפן הפנימי.

## בנייה
הבנייה רצה ב־GitHub Actions (קובץ `.github/workflows/build.yml`) בכל דחיפה ל־main. קובץ ההתקנה מתפרסם ב־Releases:
https://github.com/amitbusi10-pixel/run-android/releases/latest/download/al-haderech.apk

צריך להתקין מחדש רק כשמשנים את העטיפה עצמה (הרשאות, תוספים, אייקון), לא כשמשנים את האתר.

## חתימה
קובץ החתימה נמצא מחוץ למאגר, בתיקייה `android-signing` שליד התיקייה הזו, ושמור גם כסוד במאגר (`KEYSTORE_B64`, `KEYSTORE_PASS`). בלי אותו קובץ אי אפשר לעדכן את האפליקציה שכבר מותקנת, אז לא מוחקים אותו.
